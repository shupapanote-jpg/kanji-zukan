# 无𪚥𠕄丩丶

Safariで使える、ホーム画面に追加可能なWebアプリです。登録画面と辞書画面は別々です。辞書は読み方の五十音順に並び、漢字の見出しと読み方を表示し、その下に意味と例文を横並びで載せます。1ページに上段5項目・下段5項目まで表示します。左右のスワイプ、矢印ボタン、キーボードの左右キーでページをめくれます。漢字・読み方・意味・用例から検索できます。

漢字はキーボード入力やサイトからの貼り付け、Apple Pencil・指での手書き、写真・スクリーンショットから登録できます。出典（サイト名・URL、本の題名・ページ）も記録できます。編集、削除、JSONでの書き出しと読み込みにも対応します。手書き部分は画像のまま保存するため、字形を自動認識してテキスト化する機能はありません。

## 別のiPadで使う

このフォルダー一式をWebサイトとして公開すると、iPadのSafariでURLを開き「共有」→「ホーム画面に追加」でアプリのように使えます。データは端末ごとに保存されるため、別のiPadへ移すときは「辞書を書き出す」で作ったJSONファイルをAirDropなどで渡し、新しいiPadの「辞書を読みこむ」で選びます。

## ファイル

- index.html アプリ本体
- manifest.json ホーム画面追加用の設定
- sw.js オフライン起動用
- icon.svg ホーム画面アイコン
